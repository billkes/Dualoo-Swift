## 提交前图片检测（强制）

每一次要 `git commit` 之前，先扫描本包工作区内全部图片资源（含 `png` / `jpg` / `jpeg` / `webp` / `gif` / `heic` 等常见格式，跳过 `node_modules`、`.git`、`build`、`DerivedData`）。

- 若发现**单张超过 300KB** 的图片：列出路径与体积，**停止后续步骤**，等待用户指令后再继续。
- 若无超限图片：再继续本次提交及后续分支操作。
