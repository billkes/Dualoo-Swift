# 卸载模拟器应用

用命令卸载当前 iOS 模拟器上的本包 App（内存不足时主屏长按常点不出卸载）。

1. 从本包 `本包登记信息.json` / `register.json` 的 `bundleId` 读取包名；若无则从 `*.pbxproj` / `project.yml` 的 `PRODUCT_BUNDLE_IDENTIFIER` 解析（跳过 Tests）。
2. 对已启动模拟器执行：`xcrun simctl uninstall booted <BundleID>`；若需指定设备则先 `xcrun simctl list devices booted` 再 `xcrun simctl uninstall <UDID> <BundleID>`。
3. 汇报卸载结果；失败时给出 Bundle ID 与错误原文。
